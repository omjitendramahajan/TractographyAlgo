# A Multimodal Tractography Approach to Structural Brain Mapping

MEng research project by Om Jitendra Mahajan, supervised by Dr Amy Howard at Imperial College London.

This project asks whether pixel-scale microscopy can constrain ambiguous diffusion MRI fibre orientations during tractography without first averaging the microscopy onto the diffusion grid. It implements a hybrid probabilistic tracker combining diffusion MRI with polarisation-sensitive optical coherence tomography (PS-OCT) at their native resolutions.

## Code sample reading guide

The core contribution can be reviewed without downloading the imaging data. Start with the following two files; the analysis script is optional further reading.

| Read in order | Focus | Purpose |
| --- | --- | --- |
| [tractography/tracker.py](tractography/tracker.py) | `_psoct_constrained_step`, then `_get_direction` | Microscopy-constrained population selection, posterior sampling and diffusion-only fallback. |
| [tractography/psoct.py](tractography/psoct.py) | `PSOCTData.get_orientation` | Finds the nearest microscopy pixel within the enclosing diffusion voxel and maps its orientation into the tracking frame using the existing registration utilities. |

For supporting detail, [tractography/bedpostx.py](tractography/bedpostx.py) loads diffusion posterior samples and supplies population-specific orientation draws. [tractography/run_tractography.py](tractography/run_tractography.py) assembles the tracking workflow. The simulation, plotting and results folders contain the wider research workflow and are not prerequisites for reading the core algorithm.

## How the hybrid step works

1. Read candidate fibre populations from the voxel-scale BEDPOSTX diffusion model.
2. Find the nearest available PS-OCT pixel at the continuous tracking position, retaining its native-resolution orientation and slide normal.
3. Compare candidate dyads with microscopy in the slide plane. Where a previous heading exists, score eligible populations using:

   `score = (1 - alpha) * microscopy_alignment + alpha * trajectory_alignment`

   Alignment uses absolute dot products between normalised vectors. The microscopy comparison is in-plane; trajectory alignment uses the full 3D dyad. At a seed without a previous heading, the microscopy score is used alone.
4. Draw a 3D orientation from the selected population's diffusion posterior. The method blends selection scores, not the microscopy and diffusion direction vectors.
5. If microscopy cannot provide a usable constraint, fall back to diffusion-only tracking. Curvature limits and anatomical masks govern propagation and retention.

The project builds on BEDPOSTX diffusion estimates and the existing [`cmc_hybrid`](https://github.com/Jackinfire/cmc_hybrid) coordinate-mapping utilities. Its contribution includes the hybrid tracking rule, sub-voxel microscopy lookup, baseline implementation and evaluation workflow; it does not implement the upstream diffusion model or registration from scratch.

## Findings reported in the final MEng report

The forceps major was reconstructed in a co-registered macaque dataset associated with NIH BRAIN CONNECTS. Mean reconstructed tract volume decreased from 2,847 to 615 mm³, approximately 4.6-fold, relative to the diffusion-only baseline. Population selection differed at about 13.08% of constrained steps, concentrated in crossing-fibre regions.

Tracking with even-indexed microscopy slices and evaluating against odd-indexed slices gave a median acute in-plane angular error of 16.5°. Adjacent slices are spatially autocorrelated: this measures consistency with unused microscopy, not fully independent validation. Smaller tract volume alone does not establish anatomical accuracy. Output also depends strongly on the alignment weight and curvature threshold.

These are results reported in the final thesis, not results regenerated by installing this repository.

## Dependencies and data access

The code uses Python, NumPy, fslpy and NiBabel; plotting and analysis also use Matplotlib. See [requirements.txt](requirements.txt) and the imports in the selected scripts. The `cmc_hybrid` dependency is configured as a Git submodule:

```bash
git clone --recurse-submodules https://github.com/omjitendramahajan/TractographyAlgo.git
cd TractographyAlgo
python -m pip install -r requirements.txt matplotlib
```

This installs the listed Python packages; it does not supply all research inputs or configure the complete imaging environment. Full runs require BEDPOSTX outputs, co-registered PS-OCT slides and anatomical masks. The final report states that the multimodal dataset is not publicly released and that inputs are held by the Oxford CMC group, subject to its access policies and permissions.

Several scripts retain machine-specific paths. Configure these for your data and make the `cmc_hybrid` package importable before running analyses. This repository is a research implementation, not a data-bundled, one-command demonstration. See the [analysis guide](scripts/results/README.md) for the wider evaluation workflow.
